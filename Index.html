Before You Order

What To Have Ready

Having these ready speeds up the design process and reduces revisions.

✓
Exact Text / ContentAll wording that must appear on the design.
✓
LogoA high-resolution logo file, if applicable.
✓
Brand ColorsHex codes or examples of your brand palette.
✓
Required DimensionsExact size or platform the design is for.
✓
Reference / Example ImagesAny style you'd like the design to follow.
✓
DeadlineWhen you need the final files delivered.
✓
Preferred File FormatPNG, JPG, PDF or source file.
✓
Special InstructionsAnything else the designer should know.
